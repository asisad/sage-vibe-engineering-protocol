# SENS proposals only

Place a proposed `<sens-id>.json` here only through the reviewed repository
workflow. Start from `../registration.example.json`; reference it in
`../registry.json` after schema/context review. No implementation is registered
now. A proposal is not an active service or an execution/installation permission.

This directory is not watched, no file is executed and no service is started.
The SENS implementation belongs to its independent repository. See
`../docs/CONNECTING_SENS.fa-en.md` for future adapter acceptance requirements.
