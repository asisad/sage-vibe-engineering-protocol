# Contributing to SAGE

1. Read the formalized protocol and v0.7 frozen baseline.
2. Keep changes provider-neutral and scoped.
3. Add or update schema, policy, fixture and tests together.
4. Preserve stable IDs, provenance and evidence links.
5. Run `.\sage.ps1 ci` before opening a pull request.
6. Never add live credentials, targets or unreviewed external execution.
