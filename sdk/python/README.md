# SAGE Python SDK

Dependency-free helpers for loading and validating SAGE contract artifacts. The SDK is a projection of the provider-neutral SAGE contracts; it does not grant authority or execute external adapters.

## فارسی

این SDK برای خواندن و اعتبارسنجی Artifactهای قرارداد SAGE است و به‌تنهایی هیچ مجوزی ایجاد نمی‌کند و Adapter خارجی را اجرا نمی‌کند.
