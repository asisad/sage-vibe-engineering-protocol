# ADR — Optional OpenHands coding engine

Date: 2026-10-24. Status: **NOT ADOPTED IN CURRENT CONTRACT**.
Tracking: [Issue #4](https://github.com/asisad/sage-vibe-engineering-protocol/issues/4).

SAGE owns planning, permissions, scope, budget, state, evidence and verification.
Ruflo coordinates explicit tasks with the external Codex worker. The default
engine and successful previous workflows remain unchanged.

An isolated SDK1.58.1 prototype produced two real accepted SAGE deliveries,
using the existing controller and separate review. Incremental value under the
current data-only, single-response contract was not demonstrated. Native iterative
tools and remote Agent Server introduce other execution boundaries; those
capabilities were not activated or independently proven.

No SDK dependency, production adapter, parallel planner, permissions, memory,
catalog or ledger is admitted. The experiment remains in Git history, outside
the final runtime. A dormant implementation without demonstrated need would
add maintenance and routing ambiguity.

**تصمیم:** OpenHands در این نسخه به محصول اضافه نمی‌شود؛ امکان اتصال آزمایشی
اثبات شد، ولی ارزش افزودهٔ لازم برای نگهداری موتور دوم اثبات نشد. مالکیت اجرا
و شواهد با سیج و اتصال Ruflo + Codex محفوظ است.

Historical baselines, different prompts/stages, charged receipt bootstrap failures
and R2 review stops prevent engine-superiority claims. Billing and peak resources
are unknown. See [report](../verification/OPENHANDS_SDK_v1.58.1_EVALUATION.fa-en.md)
and [sanitized receipts](../verification/OPENHANDS_SDK_v1.58.1_RESULTS.json).

Reconsider for a concrete unmet execution need, with new scoped evidence. A
future adapter still requires SAGE's contract, disabled feature flag, negative
CI tests, independent acceptance, receipts and rollback.
