APIجو / API Discovery

کشف API از چند مرجع، بازیابی دانش مستند، و درخواست دسترسی امن با تأیید مالک. این پنل فقط داده‌های عمومی را نگهداری می‌کند؛ رمزهای واقعی در Agent Vault قرار می‌گیرند.

چه APIای نیاز داری؟

جست‌وجو در کاتالوگ‌ها؛ نتیجه صرفاً نامزد است و قبل از استفاده باید مستندات رسمی، قیمت، مجوز و وضعیت فنی بررسی شود.
داده‌های نمونهٔ آفلاین از پیش بارگذاری می‌شوند.

بافت مستند برای ایجنت‌های SAGE

بازیابی مبتنی بر SQLite FTS5 همراه با نشانی منابع و زمان ثبت. این بخش بستهٔ Context برای LLM می‌سازد، ولی خودش بدون اتصال مدل زبانی پاسخ مولد تولید نمی‌کند.

کلیدهای API و توکن‌های تأیید هرگز وارد Context نمی‌شوند.
برای دیدن بستهٔ دانش، ابتدا جست‌وجو کن.

پنل امن API Key

کلیدهای قبلی یا جدید را مستقیماً در پنل رمزنگاری‌شدهٔ Agent Vault وارد می‌کنی؛ APIجو مقدار آن‌ها را نمی‌خواند، کپی نمی‌کند یا ذخیره نمی‌کند.

مسیر: ایجاد حساب مالک و Vault ← افزودن Credential ← تعریف Service با Host مشخص ← ایجاد Agent Token محدود ← درخواست دسترسی و تأیید مالک. سپس Agent از Proxy با کلید تزریق‌شده استفاده می‌کند، نه از رمز خام.

بازکردن پنل Agent Vaultراهنمای رسمی
Agent Vault باید جداگانه روی رایانه اجرا شود. تا پیش از راه‌اندازی آن، این دکمه پنل فعالی باز نمی‌کند. «تأیید» برای تعریف دسترسی است و به معنای تأیید تک‌تک درخواست‌های API نیست؛ محدودیت و انقضای مجوز باید در Vault تنظیم شود.

مثال درخواست مجوز توسط APIجو

python api_jo.py propose --service weather-api --host api.example.org --credential-key WEATHER_API_KEY --reason "Weather forecast for my app"

نام دامنهٔ مثال را با دامنهٔ واقعی ارائه‌دهنده جایگزین کن. هیچ کلید واقعی را در خط فرمان یا چت ننویس.
